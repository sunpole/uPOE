# Currency tiers

Working reference for the uPOE Currency section.

## uPOE mapping

- `Simple` — low-value/common currency.
- `Medium` — useful mid-value currency.
- `High` — expensive/high-priority currency with sound.
- `Current League` — all 3.29 Allflame-specific currency and currency-like items, visually separated from the regular economy tiers.
