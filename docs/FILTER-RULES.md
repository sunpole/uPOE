# Filter Rules

## Основной принцип

Path of Exile обрабатывает правила фильтра сверху вниз. Более важные и более специфичные правила должны располагаться выше общих.

## Порядок разработки uPOE

1. Current League / специальные исключения.
2. High-value предметы.
3. Medium-value предметы.
4. Simple / обычные предметы.
5. Общие fallback-правила.

## Правила внесения изменений

- Один класс предметов — один законченный этап.
- Не добавлять BaseType по памяти без проверки актуального источника.
- Не смешивать визуальную ценность предмета с его игровым классом.
- Экономические ориентиры сверять с FilterBlade/NeverSink, но не копировать их визуальный стиль.
- Любое изменение, влияющее на видимость дорогих предметов, фиксировать в CHANGELOG.md.
