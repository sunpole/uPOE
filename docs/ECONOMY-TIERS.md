# uPOE Economy Tier Rules

## Базовая единица цены

Для классификации предметов по стоимости uPOE использует **Chaos Orb (c)** как основную единицу.

Причина: текущий рынок PoE 1 / Allflame публикует и сравнивает цены в Chaos Orb. Divine Orb используется как крупная дополнительная единица для дорогих предметов.

Контрольная точка на 2026-08-29: **1 Divine Orb ≈ 258 Chaos Orb**. Этот курс плавающий и должен обновляться вместе с экономикой лиги.

## Строгие ценовые тиры

| Tier | uPOE name | Диапазон стоимости | Правило |
|---|---|---:|---|
| 1 | SIMPLE | `< 10c` | дешёвая валюта |
| 2 | MEDIUM | `>= 10c` и `< 1 Divine` | заметная, но не топовая валюта |
| 3 | HIGH | `>= 1 Divine` | дорогая / топовая валюта |

При курсе 1 Divine = 258c текущие числовые границы выглядят так:

- SIMPLE: `< 10c`
- MEDIUM: `10c ... 257.99c`
- HIGH: `>= 258c`

## Непересекаемость

Это обязательное правило проекта:

- предмет из MEDIUM не может стоить дешевле границы SIMPLE;
- предмет из HIGH не может стоить дешевле границы MEDIUM;
- ровно `10c` уже относится к MEDIUM;
- ровно `1 Divine` уже относится к HIGH;
- исключений по имени предмета нет: ценовой tier определяется ценой.

Формально:

`max(SIMPLE) < min(MEDIUM) < min(HIGH)`

## Источник цены

При автоматизации использовать данные официального Currency Exchange через проверенный публичный источник/адаптер. Для защиты от часовых скачков предпочтительно классифицировать по устойчивой цене (например, 24h median), а не по одиночному краткому всплеску.

Если свежей надёжной цены нет, предмет нельзя автоматически переоценивать только по догадке.

## League items

`CURRENT LEAGUE / ALLFLAME` — это **тип/метка предмета, а не четвёртый ценовой tier**.

League-предмет всё равно получает стоимость SIMPLE / MEDIUM / HIGH по тем же границам. Его league-оформление может быть дополнительным визуальным слоем, но не должно нарушать ценовую иерархию.

## HIGH actions

Для HIGH currency сейчас зафиксировано:

- `PlayAlertSound 1 300`
- `PlayEffect Green`

MinimapIcon назначается отдельно только самым дорогим предметам после корректного полного пересчёта рынка:

- market TOP 1–5 -> `MinimapIcon 0 Green Cross`
- market TOP 6–10 -> `MinimapIcon 0 Green Circle`
- остальные -> без MinimapIcon

TOP-10 должен рассчитываться из полной актуальной выборки, а не из частичного списка.
